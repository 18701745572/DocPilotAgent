# 用户服务接口文档

## 创建用户

- 路径：`POST /api/v1/users`
- 请求体：
  - `username` (string, 必填)
  - `email` (string, 必填)
- 响应：`201`，返回新建用户对象
- 错误码：
  - `40001` 用户名已存在
  - `40002` 邮箱格式非法

## 查询用户

- 路径：`GET /api/v1/users/{id}`
- 响应：`200` 返回用户对象；不存在返回 `404`

## 更新用户

- 路径：`PATCH /api/v1/users/{id}`
- 仅允许更新 `email` 字段
