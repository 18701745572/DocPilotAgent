# 用户服务接口文档

> 用户服务的对外 HTTP 接口规范与错误码定义。

## 创建用户

- 方法：`POST /api/v1/users`
- 请求体：
  - `username` (string, 必填)：用户名，3~32 字符
  - `email` (string, 必填)：邮箱
- 响应：
  - `201 Created`：返回新建用户对象，含 `id`
  - `400 Bad Request`：参数非法
  - `409 Conflict`：用户名或邮箱已存在

## 查询用户

- 方法：`GET /api/v1/users/{id}`
- 路径参数：`id` (integer)
- 响应：
  - `200 OK`：返回用户对象
  - `404 Not Found`：用户不存在

## 错误码

| 错误码 | 含义 | 触发场景 |
|---|---|---|
| `40001` | 用户名已存在 | 创建用户时 username 冲突 |
| `40002` | 邮箱格式非法 | 邮箱不匹配规范 |
| `40003` | 邮箱已被占用 | 创建用户时 email 冲突 |
| `40401` | 用户不存在 | 查询接口找不到 id |
