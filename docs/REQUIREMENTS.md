# 需求规格 (REQUIREMENTS)

> DocPilotAgent · 研发文档助手智能体 · 只读型 RAG 助手

本文件锁定项目的功能、非功能需求、约束与典型用例。任何实现必须满足本规格；若本规格变化，则需同步更新 [DESIGN.md](./DESIGN.md) 与 [API.md](./API.md)。

---

## 1. 角色定位

| 项 | 说明 |
|---|---|
| 名称 | DocPilotAgent |
| 类型 | 只读型研发文档助手智能体 |
| 用户 | 研发人员（含排障、问答、查阅文档场景） |
| 一句话定位 | 读取本地知识库与日志，回答研发问题并生成调试建议；**不可修改代码** |

---

## 2. 功能需求 (FR)

### FR-1 知识库索引
- FR-1.1 递归扫描 `DOCS_DIR` 下所有 `.md` 文件
- FR-1.2 按 Markdown 结构切分（标题/段落优先），保留 `source` 元数据
- FR-1.3 向量化后写入 Milvus Lite 文档集合
- FR-1.4 支持增量重建（重新 `index` 即覆盖）

### FR-2 研发问答
- FR-2.1 用户提交问题 → 检索相关文档片段 → 注入历史记忆 → LLM 生成回答
- FR-2.2 回答需引用来源（文件路径）
- FR-2.3 模型可主动调用只读工具补全信息

### FR-3 多数据源
- FR-3.1 文档源：本地 Markdown（知识库）
- FR-3.2 日志源：本地日志文件目录（按关键词搜索报错行）
- FR-3.3 文件读取：读取白名单目录内的任意文件内容

### FR-4 跨会话记忆
- FR-4.1 每轮 Q&A 向量化持久化到 Milvus 记忆集合
- FR-4.2 新问题到达时，按语义相关性召回最相关历史片段（默认 top-3）注入上下文
- FR-4.3 跨进程持久化（重启不丢失）
- FR-4.4 支持按会话隔离（`SESSION_ID`）
- FR-4.5 支持清空（`reset` 命令）

### FR-5 CLI 接口
- FR-5.1 `index`：索引知识库
- FR-5.2 `ask <question>`：单次提问
- FR-5.3 `ask <question> --verbose`：显示中间步骤
- FR-5.4 `reset`：清空跨会话记忆
- FR-5.5 `--help`：列出所有命令与参数

## 3. 非功能需求 (NFR)

| 编号 | 维度 | 要求 |
|---|---|---|
| NFR-1 | 安全性 | 智能体不拥有任何写文件/执行命令能力，**不可修改代码** |
| NFR-2 | 安全性 | 文件读取工具仅允许 `docs/` 与 `logs/` 目录（路径白名单） |
| NFR-3 | 可移植性 | OpenAI 兼容接口，可切换 OpenAI / 豆包 / DeepSeek / Qwen |
| NFR-4 | 部署 | Milvus Lite 本地文件，无需独立服务/Docker |
| NFR-5 | 兼容性 | Python ≥ 3.10 |
| NFR-6 | 隐私 | 全部本地数据（知识库、日志、向量库、记忆），不上传 |
| NFR-7 | 可观测 | CLI 输出含来源引用与命中片段数 |
| NFR-8 | 健壮 | LLM 解析错误时降级而非崩溃 |

## 4. 约束（输出权限）

> 本项目的核心练习点之一，必须双保险落地。

| 层 | 机制 | 说明 |
|---|---|---|
| 工具层 | 工具白名单 | 仅暴露 `search_docs` / `read_file` / `search_logs`，**根本不提供**写文件/执行命令工具 |
| 提示词层 | SYSTEM_PROMPT | 明确声明"只读助手，不可修改代码"，用户要求改代码时改为给出调试建议 |
| 路径层 | `read_file` 白名单 | 即便被诱导，也只能读 `docs/` `logs/`，无法触及源代码 |

当用户要求"帮我改这段代码"时，智能体应：
1. 拒绝执行修改；
2. 改为定位问题、解释原因、给出建议（指向文档与日志证据）。

## 5. 典型用例

### UC-1 排查报错
> 用户：`docpilot ask "服务启动报 NullPointerException 怎么排查？"`
> 系统：检索 OOM/排错文档 + 搜索日志中匹配行 → 给出排查步骤与日志证据

### UC-2 查阅接口
> 用户：`docpilot ask "用户接口 40001 是什么错误？"`
> 系统：检索 user-service.md → 命中错误码定义 → 引用来源回答

### UC-3 跨会话记忆
> 第一次会话：问 A，回答并存记忆
> 第二次会话：问"上次那个问题怎么处理的？" → 召回记忆片段 → 基于历史回答

### UC-4 拒绝改代码
> 用户：`docpilot ask "帮我修改 UserService.create 修复 NPE"`
> 系统：拒绝修改，改为定位 NPE 位置（UserService.java:42）、引用排错指南、给出调试建议

## 7. 验收标准

- [ ] `docpilot index` 能索引示例 docs/，提示写入片段数
- [ ] `docpilot ask` 能基于文档回答，回答含来源
- [ ] 跨进程重启后，记忆仍可召回
- [ ] `docpilot reset` 后记忆清空
- [ ] 模型无法调用任何写工具（工具列表无写工具）
- [ ] `read_file` 拒绝访问 docs/logs 之外的路径
- [ ] LLM 兼容 base_url 切换（豆包/DeepSeek 至少验证一种）
